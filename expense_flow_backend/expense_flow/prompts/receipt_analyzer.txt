Task: Add Item Categories to Receipt JSON

Input Structure
The input is a JSON receipt with:
- Merchant information (name, address)
- List of purchased items (description, quantity, total_price)
- Transaction total and datetime
- Reference data in `similar_items` field

Output Requirements
1. PRESERVE ALL ORIGINAL FIELDS: Include `merchant`, `items`, `total`, and `transaction_datetime` exactly as provided
2. ADD CATEGORIES: Add a "category" field to each item in the items list
3. REMOVE similar_items: Do not include the `similar_items` field in the output

Output Validation Checklist (VERIFY BEFORE SUBMITTING)
- Merchant object with name and address is preserved
- All items have exactly one category assigned
- All category values match the predefined category names exactly
- All original data is preserved
- similar_items field is removed
- JSON structure is maintained

Categories
Choose ONE category for each item from this list only:
1. groceries
2. alcoholic_beverages
3. personal_care
4. household
5. clothing
6. entertainment
7. transportation
8. pet
9. other

Categorization Rules (In Priority Order)
1. If item is a discount (OPUST, rabat) → Use same category as original item
2. If item is a carrying/storage solution (reklamówka, torba) → household
3. If item is food/drink:
   - If contains alcohol → alcoholic_beverages
   - Otherwise → groceries
4. If description is empty or unclear → other
5. If item clearly matches another category → Use that category
6. Shopping bags and packaging → household

Category Definitions
- groceries: Food, fruits, vegetables, non-alcoholic beverages, soft drinks, ingredients, spices, meat, fish, dairy, bread, coffee, tea
- alcoholic_beverages: Beer, wine, whisky, vodka, gin and other alcoholic drinks
- personal_care: Hygiene products, cosmetics, medications, medical items, soap, deodorant
- household: Cleaning supplies, decorative items, home decor, tools, maintenance items, shopping bags, storage containers, plants
- clothing: Apparel, shoes, accessories, bags for wearing
- entertainment: Books, electronics, games, toys (non-pet), magazines
- transportation: Gas, parking tickets, car supplies
- pet: Pet food, pet supplies, pet toys
- other: Items not fitting above categories or with empty descriptions

Instructions
1. Examine input JSON and keep ALL original fields (merchant, items, total, transaction_datetime)
2. Categorize each item using the rules above
3. Add category field to each item in items array
4. Remove the similar_items field
5. Verify all requirements before submitting

Output Format
The output must be a JSON object with:
1. A merchant object (containing name and address)
2. An items array (with each item containing description, quantity, total_price, and category)
3. A total field
4. A transaction_datetime field

IMPORTANT
- Output ONLY valid JSON - no comments or explanations
- Do NOT modify any existing values
- Do NOT omit any original fields (especially merchant)
- Verify JSON structure is valid

Example Input (Structure)
{
  "merchant": {
    "name": "STORE NAME",
    "address": "STORE ADDRESS"
  },
  "items": [
    {
      "description": "ITEM DESCRIPTION",
      "quantity": 1.0,
      "total_price": 10.0
    }
  ],
  "total": 10.0,
  "transaction_datetime": "2023-01-01 12:00:00",
  "similar_items": { ... }
}

Example Output (Structure)
{
  "merchant": {
    "name": "STORE NAME",
    "address": "STORE ADDRESS"
  },
  "items": [
    {
      "description": "ITEM DESCRIPTION",
      "quantity": 1.0,
      "total_price": 10.0,
      "category": "groceries"
    }
  ],
  "total": 10.0,
  "transaction_datetime": "2023-01-01 12:00:00"
}
