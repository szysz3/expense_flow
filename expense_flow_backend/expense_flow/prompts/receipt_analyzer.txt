Priority Category Decision Process:
1. CHECK SIMILAR ITEMS FIRST: Use similar items with high scores (>0.8) as primary reference
2. DISCOUNTS: Is item a discount (OPUST, rabat)? → Use same category as original item
3. BAGS: Is item a carrying/storage solution (reklamówka, torba)? → household
4. ALCOHOL: Is item food/drink containing alcohol? → alcoholic_beverages
5. FOOD: Is item non-alcoholic food/drink? → groceries
6. EMPTY: Is description empty or unclear? → other
7. MATCHING: Does item clearly match another specific category? → Use that category

Rules:
